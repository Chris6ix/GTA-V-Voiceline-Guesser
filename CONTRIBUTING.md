# Contributing to GTA V Voiceline Guesser

Thank you for your interest in contributing to GTA V Voiceline Guesser!

Contributions are welcome, including bug fixes, balancing changes, performance improvements, gameplay improvements, documentation, tools, and other improvements to the project.

## Development model

The official version of GTA V Voiceline Guesser is maintained in the [official repository](https://github.com/Chris6ix/GTA-V-Voiceline-Guesser).

The goal of contributions is to improve the official version of the game.

You are welcome to:

- fork the repository;
- create development branches;
- modify the source code;
- experiment with gameplay and balance;
- compile and test your changes privately; and
- submit pull requests containing changes you believe should be included in the official version.

You do not need permission before experimenting with the source code privately.

## Pull requests

Pull requests are the preferred way to contribute changes.

Submitting a pull request does not guarantee that the changes will be accepted. The project maintainer may modify, reject, or request changes to a contribution before merging it.

The maintainer may also incorporate useful ideas from a contribution into the project in a different implementation.

Please keep contributions reasonably focused where practical. Large changes may be discussed before implementation.

## Code style and conventions

When submitting changes intended to be merged into the official project, please follow the existing code style, formatting, naming conventions, and general structure as closely as reasonably possible to keep the project's code consistent. Avoid unrelated formatting changes or unnecessary refactoring.

Contributions may be adjusted by the maintainer to align with the project's conventions before being merged.

## Copyright and contributions

You retain copyright in original material that you contribute unless you separately agree to transfer that copyright.

By submitting a contribution, you grant the project maintainer the rights described in the project's Source-Available License.

In particular, you permit the contribution to be modified and incorporated into the official project and distributed as part of official releases of the game.

This is intended to keep the project under one coherent licensing framework rather than having individual portions of the project subject to unrelated contributor licenses.

## Attribution

Contributors are welcome to identify themselves in appropriate places.

Depending on the size and nature of the contribution, attribution may appear in:
- source-code comments;
- documentation;
- commit history;
- release notes;
- a contributors page;
- in-game credits; or
- another appropriate location.

Attribution is not required in every individual source file.

## Third-party material

Please do not submit code, artwork, music, sounds, fonts, textures, models, or other material that you do not have permission to contribute.

Third-party material must retain its applicable copyright notices and license requirements.

If your contribution incorporates third-party material, clearly identify it in the pull request and provide the applicable license information.

The project's main Source-Available License does not override the licenses of third-party libraries or assets.

## Distribution

The source code is available for development and contribution, but the project does not grant permission to distribute the game or modified playable versions of the game.

Please do not publish compiled builds, installers, game packages, or unofficial downloadable releases.

If you make a private development build, that is fine.

If you want other people to test your changes, the preferred approach is to submit a pull request so that the changes can be reviewed and, where appropriate, incorporated into the official project.

## Questions

If you are unsure whether something can be contributed, please open an issue or discussion before submitting it.
